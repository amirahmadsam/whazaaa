# دیده‌بان بورس — نسخه‌ی اندروید

همان افزونه‌ی «دیده‌بان بورس» (v2.12.0) داخل یک اپ اندروید. اپ سایت TSETMC را در WebView باز می‌کند، اسکریپت‌های افزونه را خودکار روی صفحه‌ها تزریق می‌کند و درخواست‌های شبکه‌ی افزونه (API های cdn.tsetmc و کدال، فایل اکسل مالی) را خودش از سمت اپ می‌زند (بدون CORS). ذخیره‌ی داده‌ها داخل حافظه‌ی اپ است.

## ساخت APK (راه آسان: GitHub Actions)
1. یک repository خصوصی در GitHub بساز و محتوای این پوشه را در آن آپلود کن (پوشه‌ی `.github` هم باید باشد).
2. تب **Actions** ← «Build APK» ← **Run workflow** (یا خودکار با اولین push اجرا می‌شود).
3. بعد از ~۴ دقیقه، از پایین صفحه‌ی همان اجرا، artifact با نام `didehban-bourse-apk` را دانلود کن؛ داخلش `app-debug.apk` است.
4. APK را روی گوشی نصب کن (اجازه‌ی «نصب از منبع ناشناخته» را بده).

## ساخت با Android Studio
پوشه را باز کن ← Build ← Build APK(s). (JDK 17، Android SDK 34)

## به‌روز کردن افزونه
فایل‌های نسخه‌ی جدید را در `extension-src/` بریز و اجرا کن: `python3 tools/build_bundle.py` — این `app/src/main/assets/bundle.js` را دوباره می‌سازد.

## نکته‌ها

- نیاز به Android System WebView به‌روز دارد (اندروید ۷+).


## نحوه‌ی کار
اپ خود سایت را نشان نمی‌دهد: صفحه‌های خود برنامه (`app/src/main/assets/www`) شامل جستجوی نماد و پنل تمام‌صفحه‌ی دیده‌بان است و همه‌ی داده‌ها در پس‌زمینه از API سایت TSETMC و کدال گرفته می‌شود. دیده‌بان بازار (اسکرینر) از یک وب‌ویوی نامرئی استفاده می‌کند.

## محدودیت‌ها
- تب «🏦 مالی» که جدول‌ها را از خود صفحه‌ی TSETMC می‌خواند در اپ داده‌ای نمی‌گیرد؛ ورود دستی/اکسل کدال کار می‌کند.
- «خروجی پشتیبان» (دانلود فایل) هنوز در اپ پشتیبانی نشده؛ «بازیابی» کار می‌کند.
